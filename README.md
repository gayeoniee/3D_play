# 동글동글 · Eggy on Ice

기본 홈은 내 달걀이 산책하는 고정 시점 3D 마을입니다. 마을의 경기장 또는 출전 버튼으로 기존 밀어내기 게임을 시작합니다. 경기 화면의 `마을로` 버튼으로 언제든 돌아올 수 있습니다.

## 마을과 달걀 수집
- 일반 6종, 희귀 6종, 에픽 6종의 총 18종. 각 달걀의 외형, 스킬, 파워·이동·버티기 수치가 다릅니다.
- 처음에는 무작위 일반 달걀 1마리와 별조각 300개를 받습니다.
- 1회 뽑기 100개. 일반 60%, 희귀 32%, 에픽 8%이며 같은 등급 내 6종은 동일 확률입니다.
- 중복은 별조각 40개로 환급합니다. 게임 내 재화만 사용하며 결제 기능은 없습니다.
- 누적 3승마다 뽑기권 1장을 받습니다(공동 1위 포함). 뽑기권을 먼저 사용하고, 없으면 별조각 100개를 사용합니다. 기존 승리 기록도 처음 갱신할 때 반영합니다.
- 뽑기에는 껍질이 열리는 연출과 달걀의 성격·고유 스킬·능력치 소개가 나옵니다. 연출 건너뛰기와 동작 줄이기 설정을 지원합니다.
- 집은 3채입니다. `마을 꾸미기`에서 집·나무·꽃밭·연못·분수·경기장·벤치·울타리·내 달걀을 마우스나 터치로 옮길 수 있습니다. 되돌리기와 기본 배치 복원도 지원합니다.
- 뽑기권과 소품·달걀 배치도 현재 브라우저에 자동 저장됩니다.
- 달걀이 배치한 위치를 기준으로 산책하고, 근처 벤치에서 쉬거나 꽃향기·분수를 구경하고 친구에게 손을 흔듭니다. 카메라는 고정이며 동작 줄이기 설정에서는 생활 동작을 멈춥니다.
- 달걀마다 좋아하는 것을 확인하고 12글자 이내 별명을 지을 수 있습니다. 별명은 마을, 출전 정보, 내 경기 순위에 표시됩니다.
- 중복 달걀은 별조각 40개에 더해 해당 달걀의 꾸미기 조각 1개를 줍니다. 누적 1/3/5개로 리본/밀짚모자/꽃 배지와 작은 화단을 해금합니다. 조각은 소모되지 않으며, 장식은 전투 능력치에 영향을 주지 않습니다. 착용 장식은 마을과 출전 달걀에 적용됩니다.
- 승패에 관계없이 하루 3판을 완료하면 뽑기권 1장을 자동 지급합니다. 경기 결과까지 확인해야 하며 하루에 한 번만 지급합니다. 기기의 현지 날짜 기준 자정에 갱신하며 3승 보상과 함께 받을 수 있습니다.
- 마을 아래에서 JSON 저장 파일을 내려받고 다른 브라우저에 불러올 수 있습니다. 불러오기 전 요약 확인과 취소, 직전 마을 복구를 지원합니다. 올바르지 않은 파일은 현재 마을을 변경하지 않습니다.
- 충돌 강도에 따른 찌그러짐, 충격 방향으로 튀는 별, 돌진·가속 잔상과 효과음이 있습니다. 헤더에서 소리를 켜고 끌 수 있으며 선택은 브라우저에 저장됩니다. 효과음은 첫 클릭/키 입력 이후 시작됩니다.
- 산책은 집·나무·꽃밭·벤치·연못·분수·경기장·울타리를 피하는 경로를 사용하며, 친구끼리 간격을 두고 걷습니다. 배치를 바꾸면 경로를 다시 계산합니다. 낮잠에는 눈을 감고, 이동 중과 쉬는 중의 소개 문구도 구분합니다.
- 정상 자동 저장의 복구용 사본을 함께 보관합니다. 기본 기록이 손상되면 복구 가능한 사본을 사용하며, 여러 탭에서 서로 다른 마을 기록을 덮어쓰는 것을 막습니다. 저장 공간이 없거나 차단된 경우 파일 보관 안내를 표시합니다. 브라우저 데이터 전체 삭제는 파일 백업이 필요합니다.
- 모바일에서는 3D 해상도와 그림자 크기를 줄이고 마을을 최대 30fps로 그립니다(경기 물리는 기존 120Hz). 보이지 않는 마을은 그리기를 멈춥니다. 달걀 도형을 공유하며 경기 재시작 시 개별 자원을 정리합니다. WebGL 화면이 끊기면 경기를 멈추고 복구를 기다립니다.
- 경기 중 금색 바닥 화살표가 현재 이동·스킬 방향을 가리킵니다. 자정이 지나면 인사와 일일 보상 표시가 새로 갱신됩니다. 효과음을 끄거나 다른 탭으로 이동할 때 재생 중인 소리도 정리합니다.
- 보유한 달걀만 마을에 나타나며 직접 출전할 수 있습니다. AI 5명은 전체 도감에서 무작위로 선정합니다.
- 경기 완료 보상은 순위에 따라 별조각 70~120개입니다. 도중에 마을로 나가면 보상을 주지 않습니다.
- 보유 달걀별 하루 첫 인사로 호감도 1과 별조각 20개를 얻습니다. 꽃밭 색을 바꿀 수도 있습니다.
- 보유 달걀, 별조각, 호감도, 선호 달걀, 꽃밭과 경기 기록은 현재 브라우저의 localStorage에 저장됩니다. 계정/서버 동기화는 없으며 브라우저 데이터 삭제 시 초기화됩니다.
- 전체 달걀 데이터와 능력치는 `src/eggs.js`에 있습니다.

공유 주소: https://gayeoniee.github.io/3D_play/

GitHub Pages의 `gh-pages` 브랜치에 빌드 결과를 배포했습니다. 컴퓨터를 켜둘 필요 없이 접속할 수 있으며, 각자 AI와 플레이하는 싱글플레이 게임입니다. 이후 로컬 수정은 다시 빌드·배포해야 공유 주소에 반영됩니다.

고정된 사선 카메라로 즐기는 3D 빙판 밀어내기 프로토타입입니다.
난이도를 편하게 조정했습니다. 경기장 반지름은 얼음 8.5, 불가마 7.8, 숲 8.2로 이전 버전보다 면적이 약 30% 커졌습니다. 시작 위치는 반지름의 45% 지점이며, 마지막 30초의 축소 속도는 초당 0.075입니다. AI 이동 가속은 4.8, 공격력은 캐릭터 기본값의 82%이며 첫 4초에는 스킬을 쓰지 않습니다. 이후 AI의 스킬 사용 시도 빈도도 낮췄습니다. 플레이어는 추가로 받는 밀림을 10% 줄이고 피격 중 조작·제동을 강화했습니다. 내 공격과 3초 스킬 쿨타임은 유지합니다.
로비에서 넓은 얼음섬(긴 미끄러짐), 말랑 불가마(강한 반동), 도토리 숲(쉬운 제동)을 선택할 수 있습니다. 얼음섬은 초기 버전 대비 면적이 약 75% 넓어졌습니다.
충돌 반동, 돌진 밀치기, 피격 직후 관성 유지와 짧은 캐릭터 눌림 효과를 적용했습니다. 모든 맵에서 마지막 30초에 발판이 축소됩니다.
파스텔 계란 캐릭터 18종, 플레이어 1명 + AI 5명, 관성 이동과 충돌, 스킬, 낙하 판정, 90초 경기와 마지막 30초 얼음 축소를 구현했습니다.
캐릭터는 Three.js 메시로 만든 실제 입체 모델입니다.

## 실행
```sh
npm install
npm run dev
```
터미널에 표시되는 로컬 주소를 브라우저에서 열어 주세요.

## 조작
- 방향키 / WASD: 이동 (반대 방향으로 제동)
- Space / 원형 스킬 버튼: 캐릭터 고유 스킬 (재사용 3초, 남은 시간과 원형 게이지 표시)
- Esc: 일시정지 / 계속
- 휴대폰: 가로 화면, 왼손 드래그 조이스틱 + 오른손 스킬 버튼 (동시 터치 지원)

휴대폰에서는 시작 버튼을 누르면 전체 화면과 가로 방향 고정을 시도합니다. 지원하지 않는 브라우저에서는 직접 가로로 돌리는 안내가 표시됩니다. 세로로 돌리면 일시정지하고 다시 가로로 돌리면 이어집니다. 캐릭터 선택으로 돌아가면 전체 화면을 종료합니다.

## 기본 6종의 대표 스킬
모든 스킬의 쿨타임은 3초이며 AI도 같은 규칙을 따릅니다.

| 캐릭터 | 스킬 | 효과 |
| --- | --- | --- |
| 버터 | 버터 로켓 | 강한 전방 돌진 |
| 모찌 | 모찌 보호막 | 1.2초간 밀림 75% 감소, 짧은 주변 밀치기 |
| 피치 | 피치 팡! | 주변 원형 범위의 적을 즉시 밀어냄 |
| 민트 | 민트 바람걸음 | 짧은 돌진과 1초간 이동 가속 |
| 라일락 | 라일락 회오리 | 0.9초간 주변 적을 회전 방향으로 밀어냄 |
| 소다 | 소다 물대포 | 전방 부채꼴 밀치기, 자신은 짧게 반동 |

희귀/에픽 달걀에는 둔화 지진, 2단 돌진, 강화 뿌리방패, 둔화 회오리, 보호 도약, 연사, 불꽃 후속 파동, 서리 둔화방패, 광역 번개, 달빛 가속, 무거운 꿀 회오리, 장거리 별빛 대포가 있습니다. 높은 파워는 상대에게 주는 충격을 늘리고, 이동 수치는 가속에, 버티기 수치는 받는 밀림에 영향을 줍니다.

## 순위
탈락 순서에 따라 6위부터 순위가 기록됩니다. 동일한 물리 프레임에 탈락한 캐릭터는 공동 순위입니다. 플레이어가 탈락해도 관전이 이어지고 마지막 생존자 또는 제한 시간 도달 시 전체 결과를 표시합니다. 시간 종료 시 생존자는 공동 1위입니다.

카메라 회전, 추적, 줌, 화면 흔들림이 없습니다. OS의 동작 줄이기 설정에서는 캐릭터의 장식 동작도 줄입니다.
다른 창으로 이동하면 경기가 자동으로 멈춥니다. 온라인 멀티플레이는 지원하지 않습니다.
